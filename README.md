# QinMusic · Electron 3D 音乐播放器

基于 **Electron + Three.js** 的桌面音乐播放器，界面与视觉向 **Mineradio** 对齐：
暗色沉浸式 3D 粒子舞台、随节奏脉冲的旋转唱片、歌词与特效互相衬托。

## 功能

- **首页**：推荐歌单瀑布卡片（封面 + 播放量）+ 私人FM 入口 + 我的喜欢（网易云真实喜欢歌单）+ 最近播放历史；点击歌单自动载入歌曲并播放第一首。
- **私人FM**：网易云电台接口，播放推荐歌曲，支持「下一首」连播、自动加载更多。
- **播放队列**：搜索 / 歌单 / FM 均可连续播放（下一首 / 上一首 / 播完自动切歌）。
- **无边框窗口**：去掉系统原生标题栏（顶部白框），顶栏左键拖拽移动、双击最大化；右上角自绘最小化 / 最大化 / 关闭按钮，舞台顶部保留拖拽区。
- **特效入口整合**：右上角工具按钮打开「特效 & 背景」面板，内含 7 种歌词视觉模式（两列网格）与可视化背景设置，选择特效后面板自动收起。
- **快速加载**：播放地址缓存 + 下一首预取（切歌秒开）、歌词/封面与地址解析并行、接口 8s 超时自动回退，点歌后立即切换舞台并显示加载状态。
- **「我的喜欢」秒开**：主进程缓存喜欢歌曲详情（10 分钟 TTL），首页加载时后台预热缓存，打开歌单与播放第一首无需等待全量拉取。
- **帧数选择**：设置面板新增「帧数」（30 / 60 / 120 FPS），渲染循环按所选帧率节流（留 1ms 余量，60Hz 下 60fps 不丢帧），粒子速度按帧率归一化——降低帧率不改变动画速度，只省 GPU 占用（默认 60，记忆上次选择）。
- **首次启动动态封面**：首启全屏粒子封面（点击任意处进入），封面展示期间后台初始化 3D 舞台、加载首页数据；再次启动直接进入。
- **播放模式**：顺序 / 列表循环 / 单曲循环 / 随机播放（播放条按钮一键切换，记忆上次选择；随机模式预取随机下一首）。
- **切歌淡入淡出**：自动切歌时 0.9s 淡出 + 新歌 0.5s 淡入，过渡自然；音量滑条作为基准音量。
- **断点续播**：每首歌独立记忆播放位置（10s 节流 + 暂停/退出时保存），重新播放自动续听，拖到开头即清除。
- **播放队列面板**：播放条列表按钮弹出当前队列，高亮正在播放，点击任意条目跳播；私人FM 显示推荐模式提示。
- **滑条渐变填充**：进度条与音量条均带青→紫渐变填充（跟随当前值实时更新）；音量条悬停展开（84→120px），不再挤占播放条边界。
- **底部控制栏自动隐藏**：播放中鼠标静置 3.2s 后控制栏自动下滑淡出（底部进度线常驻），移动鼠标立即浮现；悬停控制栏 / 暂停时保持显示。
- **系统托盘 + 全局媒体快捷键**（Folia 没有的桌面端功能）：托盘菜单显示/播放暂停/切歌/桌面歌词/退出；媒体键与 Alt+Shift+Space（播放暂停）、Alt+Shift+←/→（切歌）、Alt+Shift+L（桌面歌词）全局生效。
- **桌面歌词窗口**：置顶迷你窗口，卡拉 OK 逐字填充 + 进度条 + 封面，可拖拽、双击关闭；播放条 📺 按钮或全局快捷键开启。
  - **平滑插值**：歌词进度用 rAF 本地插值（不再依赖低频 timeupdate），暂停/切歌自动冻结，拖动进度条后重新同步，桌面歌词不卡顿。
- **歌曲收藏**：播放条 ♡ 按钮标记喜欢/已喜欢；与网易云喜欢歌单实时同步（接口受限时自动打开网页引导收藏）。
- **最近播放历史**：本地记忆最近 60 首，首页横向展示，点击续播。
- **歌词同步偏移**：词音不同步用 [ / ] 微调 ±0.1s（Shift 时 ±0.02s）、0 归零，每首歌独立记忆；偏移指示在舞台右上角。
- **词级歌词（YRC）**：自动获取网易云逐字歌词（词级时间戳），逐字点亮严格跟随原唱口型；无词级数据的歌曲自动回退为整行均分。
- **3D 粒子舞台**：粒子星系（带绕轴漩涡）+ 远处星层景深 + 旋转光轨圆环 + 舞台光束。
- **真 FFT 频谱环**：48 根 3D 音柱环绕唱片，随真实频谱跳动（未播放时为呼吸动画）。
- **鼓点联动**：低音击打触发冲击波扩散 + 歌词行脉冲放大 + 火花绽放 + 粒子加速。
- **封面取色氛围光**：主进程代理下载封面 → 提取主色 → 背景光 / 光轨 / 频谱 / 光束颜色全部跟随封面与歌词段落渐变（青→紫区间）。
- **歌词行尾停留 + 间奏清场**：每行按“演唱结束时间”（词级 YRC 行真实结束 / 按字数估算）点亮并在唱完后停留 0.55s；遇到间奏（下一句还早）时上一句自动淡出清屏，不会一直挂到下一句，曲词不再错位。
- **歌词舞台（Folia classic 移植）**：直接移植 Folia 的词级渲染管线——每个字**双层渲染**（发光层 + 主体层，发光脉冲独立于字形）、
  词级三态（等待=隐形+模糊 / 演唱=白色发光放大+spring 回弹 / 已唱=微转余晖）、行起始时间做种子的确定性随机构图、
  行对齐随歌词变化、行切换 blur 进出场。副歌行**金色高亮 + 词级扩散光环 + 整行光晕**（Folia chorus ripple）。
  歌词翻译（网易云 tlyric）跟随原句显示。
- **精致 SVG 图标**：全局图标替换为线性 SVG 系统（搜索 / 播放暂停 / 切歌 / 音量 / 收藏 / 桌面歌词 / 设置 / 返回 / 登录 / FM 等 14+ 处），渐变播放键 + hover 光效，替代旧 emoji/文字按钮。
- **Folia 风格背景**：封面重模糊（blur 40px / scale 1.5）+ 主色→副色对角渐变 overlay 混合 + 角落微光，
  替换了旧的径向光斑背景；鼓点脉冲改为行亮度闪动（不再覆盖词级定位）。
- **12 种歌词视觉模式**（右上角「特效 & 背景」面板切换 / 数字键 1-9 快捷切换，记忆上次选择）：
  - `经典`：Folia classic 移植（上）
  - `摆锤`：遮罩扫过逐字点亮 + 边缘亮线扫描（pendulum sweep）
  - `流光`：逐字内部流光渐变扫过整行（karaoke 逐字点亮）
  - `云阶`：歌词呈阶梯排列，副歌行登台放大
  - `回环`：歌词字符环绕成环旋转，半径随低频脉动
  - `心象`：字符从四面八方飞入汇聚成句
  - `星轨`：行星轨道——唱词驶向近地点放大点亮，其余字沿三层轨道缓转（光效克制）
  - `极光`：字符成极光幕布，行波涌动、色相慢流，唱词升起光柱
  - `瀑布`：字符坠落汇聚成行，水帘长流、唱词溅起水花与池面涟漪
  - `星河`：Mineradio star-river 移植——GPU 粒子河在歌词后方蜿蜒流淌，另有一层加色粒子光河
    浮在歌词之上（复制 Mineradio 的渲染顺序：粒子位于歌词上方），光丝拖尾 + 亮星 + 柔光星云斑，
    河面宽度随当前歌词行伸缩、色相跟随封面取色，唱字浮游 + 斜向扫光（shine）、鼓点从唱字底部漾开水波涟漪
  - `商籁`：Folia Sonnet 全引擎移植（Pixi 实时排版 / 镜头运镜 / 背景装饰 / 段落编排），歌词随镜头流动、鼓点卡点，极光背景透出增强沉浸感
  - `星海`：Mineradio 3D 歌词舞台完整移植（02-visual 全套 16 个模块、8000+ 行原样打包执行，
    `renderer/src/mr/*.js` + `mineradio-stage.js` 桥接）——独立 WebGL 场景、封面粒子背景（emily cover 预设）、
    cinema 多行发光 3D 歌词（进度卡拉OK填充 / 扫光 / 边缘增亮 / 故障扰动）、鼓点 FOV 脉冲与镜头漂移、
    封面取色调色板、切行淡出与涟漪
- **快捷键**：`空格` 播放/暂停、`←/→` 快退/快进 5 秒、`↑/↓` 音量、`1-9` 切换歌词模式、`[`/`]` 歌词同步偏移、`0` 偏移归零、双击舞台播放/暂停。
- **可视化背景系统**：舞台右上角 ◐ 打开面板——背景模式（漫游极光 / 隐现封面 / 静态）、颜色来源（封面取色 / 主题色 6 色板）、节拍响应开关、字幕可读性背景、帧数选择（30/60/120）。极光着色器随鼓点/副歌/能量实时流动，商籁模式下背景透出增强沉浸感。
## 运行

需要 Node.js 18+。

```bash
# 首次安装依赖（国内网络较慢时先设置镜像）：
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:npm_config_registry = "https://registry.npmmirror.com"
npm install

# 启动
npm start
```

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `npm start` | 构建渲染器并启动应用 |
| `npm run build` | 用 esbuild 打包渲染器（`renderer/src/app.js` → `renderer/app.js`） |
| `npm run smoke` | 无头冒烟：窗口加载成功打印 `SMOKE OK` 后自动退出 |
| `npx electron . --shot out.png` | 启动后截图到指定文件 |
| `npx electron . --shot out.png --demo-mode flow` | 截图演示模式（classic / pendolo / flow / ring / cloud / heart 任选） |
| `npx electron . --shot out.png --demo-mode classic --demo-time 20.4 --demo-pause` | 跳到指定时间并冻结，验证副歌/特定段落效果 |
| `npx electron . --dom` | 输出页面关键文本 + 喜欢缓存接口连通性（验证中文与 IPC 是否正常） |
| `npx electron . --shot-home out.png` | 启动后截图首页（调试模式自动跳过启动封面） |

## 目录结构

```
main.js              主进程：窗口 + 网易云 API + 网页登录抓 Cookie + IPC
preload.js           渲染进程安全桥接（contextBridge）
renderer/index.html  界面骨架
renderer/style.css   暗色毛玻璃主题样式
renderer/src/app.js  渲染逻辑源码（Three.js 3D 舞台 + 歌词联动 + 播放控制）
renderer/app.js      esbuild 打包产物（npm run build 生成）
```

## 常见问题

- **文字全是问号**：本版本已全部改为 UTF-8（无 BOM）编码；若重新编辑文件，请勿用 ASCII 编码保存中文。
- **搜索/播放失败**：多为网络或网易云风控，稍后重试；VIP 歌曲请先「登录网易云」。
- **GPU 报错**：控制台的 `GPU state invalid` 等是 Chromium 的无害提示，不影响使用。
- **QQ/汽水音乐**：顶部入口已预留，接口尚未接入，后续版本补齐。
